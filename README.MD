# Laundry Wallah / Laundry Mart

## Task 2: HTML Webpage

This project is a simple HTML webpage for **Laundry Wallah / Laundry Mart**, a laundry service website designed to provide information about laundry services, pricing, and booking.

## Features:

* Welcome heading for the laundry service
* About section introducing Laundry Wallah / Laundry Mart
* Laundry services list
* Price list displayed using an HTML table
* Booking form with:

  * Name
  * Email ID
  * Phone Number

* Book Now button
* Contact information
* Laundry-related image

## Technologies Used

* HTML5
